# Penalties for regularized and bias reduced estimation

Builds a penalty on regression coefficients for the `"ml"` engine. The
estimate maximizes `loglik(beta) - P(beta)`.

## Usage

``` r
penalty(
  type = c("ridge", "lasso", "elastic_net", "adaptive_lasso", "group_lasso", "scad",
    "mcp", "firth", "jeffreys", "flic", "flac", "log_f", "cauchy"),
  lambda = 1,
  alpha = NULL,
  pars = NULL,
  standardize = TRUE,
  gamma = NULL,
  weights = NULL,
  groups = NULL,
  m = 1,
  scale = 2.5
)
```

## Arguments

- type:

  Penalty type, see Details.

- lambda:

  Non-negative penalty weight.

- alpha:

  Elastic net mixing weight in `[0, 1]`.

- pars:

  Parameters whose coefficients are penalized (default all).

- standardize:

  Scale each penalized column by its standard deviation before
  penalizing (shrinkage penalties only).

- gamma:

  Adaptive lasso exponent, or the concavity of `"scad"` (default 3.7)
  and `"mcp"` (default 3).

- weights:

  Optional adaptive lasso weights.

- groups:

  Optional group labels for `"group_lasso"`.

- m:

  Degrees of freedom of the log F prior.

- scale:

  Scale of the Cauchy prior.

## Value

An object of class `regcomp_penalty`.

## Details

Smooth penalties (work with random effects):

- `"ridge"`: `P = lambda / 2 * sum(beta^2)`.

- `"firth"` (alias `"jeffreys"`): `P = -1/2 log det I(beta)`,
  Firth's (1993) penalized likelihood, equivalent to a Jeffreys
  invariant prior. For canonical links of exponential families
  (logistic, Poisson log linear) it removes the first order bias of the
  maximum likelihood estimator and gives finite estimates under
  separation. `I(beta)` is the expected information for families whose
  `eta` second derivatives do not depend on the response and the
  observed information otherwise (documented approximation).

- `"flic"`: Firth estimates with the intercept of each penalized
  predictor re estimated by maximum likelihood with the other terms as
  an offset, so average predicted probabilities equal observed
  proportions (Puhr et al. 2017).

- `"flac"`: Firth's logistic regression with added covariate: maximum
  likelihood on data augmented by pseudo observations weighted by half
  the Firth hat values (Puhr et al. 2017). Binary and binomial families
  only.

- `"log_f"`: log F(m, m) prior penalty
  `P = -sum(m/2 beta - m log(1 + exp(beta)))` (Greenland and Mansournia
  2015).

- `"cauchy"`: independent Cauchy priors with scale `scale`,
  `P = sum log(1 + (beta / scale)^2)` (Gelman et al. 2008).

Non smooth penalties (fitted by accelerated proximal gradient descent,
FISTA, for models without random effects):

- `"lasso"`: `lambda * sum(|beta|)`.

- `"elastic_net"`:
  `lambda * (alpha * sum(|beta|) + (1 - alpha) / 2 * sum(beta^2))`.

- `"adaptive_lasso"`: `lambda * sum(w_j |beta_j|)`,
  `w_j = 1 / |b_j|^gamma` from an initial maximum likelihood (or ridge)
  fit, or user `weights`.

- `"group_lasso"`: `lambda * sum_g sqrt(p_g) ||beta_g||_2` for `groups`
  (a vector naming the group of each penalized coefficient; by default
  the columns generated by one model term form a group).

- `"scad"` and `"mcp"`: folded concave penalties (Fan and Li 2001;
  Zhang 2010) fitted by the local linear approximation (Zou and Li
  2008), a few reweighted lasso steps started from the lasso.

`lambda` is on the scale of the summed log likelihood:
`lambda = n * lambda_glmnet` reproduces glmnet and ncvreg, whose losses
are averaged over observations. The SCAD and MCP thresholds act on
`lambda / n`.

Intercepts are never penalized except by `"firth"`, which acts on the
whole information matrix. Penalized estimates are not maximum likelihood
estimates. For `"firth"`, `"log_f"` and `"cauchy"` the inverse penalized
Hessian is reported as the covariance and is the usual large sample
approximation; for the others it is not a valid frequentist covariance
and p values are suppressed. Choose `lambda` by cross validation.

## Examples

``` r
# Complete separation: maximum likelihood diverges, Firth stays finite.
d <- data.frame(x = c(-2, -1, -0.5, 0.5, 1, 2), y = c(0, 0, 0, 1, 1, 1))
fit <- regcomp(y ~ x, family = "bernoulli", data = d, penalty = penalty("firth"))
coef(fit)
#> prob:(Intercept)           prob:x 
#>     3.608501e-05     1.583677e+00 
set.seed(2)
X <- matrix(rnorm(200 * 8), 200)
d2 <- data.frame(X, y = rpois(200, exp(0.5 + X[, 1] - 0.5 * X[, 2])))
fit2 <- regcomp(y ~ ., family = "poisson", data = d2,
                penalty = penalty("lasso", lambda = 5))
round(coef(fit2), 3)
#> lambda:(Intercept)          lambda:X1          lambda:X2          lambda:X3 
#>              0.488              0.984             -0.484              0.033 
#>          lambda:X4          lambda:X5          lambda:X6          lambda:X7 
#>              0.016              0.029              0.000              0.000 
#>          lambda:X8 
#>              0.119 
```
