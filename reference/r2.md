# R squared and intraclass correlation

`r2()` gives likelihood based pseudo R squared measures against the
intercept only model (McFadden; Cox and Snell; Nagelkerke) and, for the
families where it is defined, the marginal and conditional R squared of
Nakagawa, Johnson and Schielzeth (2017): the fixed effect variance, and
the fixed plus random effect variance, of the main parameter's linear
predictor over their sum with the distribution specific observation
level variance (normal: sigma^2; binary and binomial: pi^2 / 3 for
logit, 1 for probit, pi^2 / 6 for cloglog; Poisson and NB2 with log
link: the lognormal approximation from the intercept only model with the
same random effects). `icc()` gives the adjusted and conditional ICC
from the same variances.

## Usage

``` r
r2(object)

icc(object)
```

## Arguments

- object:

  A frequentist fit.

## Value

`r2()`: a named vector; `icc()`: a named vector with the adjusted and
conditional ICC.

## Examples

``` r
d <- data.frame(x = rnorm(300), g = factor(rep(1:30, each = 10)))
d$y <- rpois(300, exp(0.5 + 0.4 * d$x + rnorm(30, 0, 0.5)[d$g]))
f <- regcomp(y ~ x + (1 | g), family = "poisson", data = d)
r2(f)
#>    mcfadden   cox_snell  nagelkerke    marginal conditional 
#>   0.1387858   0.4212927   0.4296399   0.2139936   0.4767544 
icc(f)
#>    adjusted conditional 
#>   0.3342985   0.2627607 
```
